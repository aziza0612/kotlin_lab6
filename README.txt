# Laboratory 6 — Special Classes (Kotlin)

Har bir task alohida package va Main.kt faylida. IntelliJ IDEA'da Kotlin/JVM loyiha ochib,
src/main/kotlin ichiga task01 ... task15 papkalarini ko'chiring. Har bir Main.kt ichida package
nomi mos yozilgan. Alohida vazifani ishga tushirish uchun shu fayldagi main() yonidagi Run tugmasini bosing.

## Qisqa javoblar
- Enum: oldindan belgilangan constantlar to'plami; entries barcha qiymatlarni beradi.
- Sealed class/interface: subclasslar yopiq to'plam bo'lib, when barcha holatlarni tekshirishi mumkin.
- Enum oddiy nomlangan qiymatlar uchun; sealed turli ma'lumot tashuvchi holatlar/buyruqlar uchun.
- else qo'shish exhaustive tekshiruvni yashirishi mumkin, shu sabab yangi holatni unutib yuborish oson.
- task13 guard conditions uchun Kotlin 2.2+ kerak (yoki mos compiler flag).
